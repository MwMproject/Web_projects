# Site Mabasi

Ce dossier contient le remplacement statique du site Wix. Il n'y a rien à installer.

## Mise en ligne

1. Connectez-vous à l'hébergement Infomaniak avec votre logiciel FTP.
2. Copiez tout le contenu de ce dossier, y compris `.htaccess`, dans le dossier web de `mabasi.com`.
3. Vérifiez `/`, `/contact`, `/about-us`, `/services-4`, `/copy-of-galleries`, `/copy-of-suppliers`, `/copy-of-about` et `/copy-of-terms-conditions`.

| URL publique | Fichier |
|---|---|
| `/` | `index.html` |
| `/contact` | `contact.html` |
| `/about-us` | `about-us.html` |
| `/services-4` | `services-4.html` |
| `/copy-of-galleries` | `copy-of-galleries.html` |
| `/copy-of-suppliers` | `copy-of-suppliers.html` |
| `/copy-of-about` | `copy-of-about.html` |
| `/copy-of-terms-conditions` | `copy-of-terms-conditions.html` |

Le site public audité ne proposait qu'une version anglaise : aucun fichier de traduction ni `hreflang` n'est nécessaire. Le formulaire prépare un e-mail à `info@mabasi.com`.
